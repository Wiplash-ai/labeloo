# Labeloo 0.5.2 store handoff

## Release notes

- Restores normal wheel and trackpad scrolling throughout the sheet preview on
  macOS, Windows, and Linux.
- Adds pointer-centered touchpad pinch and Command/Control-wheel zoom from 65%
  through 300%, while keeping the zoom slider available.
- Removes the redundant project-name field so each sheet has one clear name;
  that sheet name now also controls CSV export filenames and print headings.
- Prints only physical pages that contain populated labels, skips blank label
  records, and avoids empty pages between populated pages.
- Hardens Letter-size page breaks for browser print and Save as PDF workflows.

## Store update summary

Scroll normally, then pinch or hold Command/Control while scrolling to zoom
toward the pointer up to 300%. Sheet names now control exports, and printing
skips pages without labels.

## Permission and privacy summary

This update adds no permissions and changes no data collection behavior.

- `storage`: local projects, imported field mappings, preferences, optional
  opaque account session, sync metadata, and pending context-menu selections.
- `contextMenus`: user-invoked capture of selected webpage text.
- `identity`: browser-owned Wiplash.ai sign-in with a one-time PKCE code; it
  does not expose the browser profile email to Labeloo.
- Optional `https://docs.google.com/*`: requested only for a shared-link Google
  Sheet import.
- Optional `https://auth.wiplash.ai/*`: requested only when the user starts
  Wiplash.ai sign-in, private Drive selection, or project sync.
- No tabs, history, scripting, clipboard, broad website, analytics, or
  advertising permission is requested.

The canonical description, search terms, permission explanation, and
compatibility disclaimer are in `LISTING.md`. The public privacy-policy URL is
`https://labs.wiplash.ai/labeloo/privacy/`.

## Reviewer path

1. Scroll normally within the print preview.
2. Pinch, or hold Command/Control while scrolling, and confirm zoom remains
   anchored beneath the pointer through 300%.
3. Open sheet settings, rename the sheet, and confirm its name appears in the
   selector and exported CSV filename.
4. Leave a complete physical page of blank label records between two populated
   pages, then print and confirm only the two populated pages are produced.

Core editing, local imports, printing, and PDF export require no account.
