# Labeloo 0.5.1 store handoff

## Release notes

- Opens the complete Labeloo workbench directly from the toolbar and reuses an
  empty browser new tab when possible.
- Imports Excel (`.xlsx`, `.xls`, `.xlsm`, `.xlsb`), Apple Numbers,
  LibreOffice Calc (`.ods`, `.fods`), CSV, TSV, and text spreadsheets.
- Lets users select a worksheet, choose row or column orientation, identify
  header and first-data rows, map unfamiliar fields, and preview records before
  importing.
- Fills existing blank labels before appending imported records.
- Imports shared-link Google Sheets after an explicit optional host-permission
  request. Signed-in users can separately choose one private Google Sheet.
- Marks duplicate printed text with red references and provides direct links
  between matching labels.
- Replaces the former Labeloo password session with optional Wiplash.ai single
  sign-on in the browser's compact authorization window. No confirmation code
  needs to be copied, and project sync remains a separate opt-in.
- Reuses prior Google authorization, closes the compact Sheet chooser after
  import, and offers an explicit **Switch Google account** action.

## Store package mapping

- Chrome: `labeloo-chrome-0.5.1.zip`
- Edge: `labeloo-edge-0.5.1.zip`
- Opera: `labeloo-opera-0.5.1.zip`
- Firefox: `labeloo-firefox-0.5.1.zip`
- Firefox source: `labeloo-firefox-source-0.5.1.zip`

All packages are generated by `npm run package:stores` under
`artifacts/packages/`.

## Permission and privacy summary

- `storage`: local projects, imported field mappings, preferences, optional
  opaque account session, sync metadata, and pending context-menu selections.
- `contextMenus`: user-invoked capture of selected webpage text.
- `identity`: browser-owned Wiplash.ai sign-in with a one-time PKCE code; it
  does not expose the browser profile email to Labeloo.
- Optional `https://docs.google.com/*`: requested only for a shared-link Google
  Sheet import.
- Optional `https://auth.wiplash.ai/*`: requested only when the user starts
  Wiplash.ai sign-in, private Drive selection, or project sync.
- No tabs, history, scripting, clipboard, broad website, analytics, or
  advertising permission is requested.

The canonical description, search terms, permission explanation, and
compatibility disclaimer are in `LISTING.md`. The public privacy-policy URL is
`https://labs.wiplash.ai/labeloo/privacy/`.

## Reviewer path

1. Click the toolbar icon and confirm the full workbench opens directly.
2. Open **Import labels** and import a supported local spreadsheet.
3. Select the worksheet and orientation, map fields, preview, and import.
4. Confirm imported records fill editable blank labels before appending.
5. Import repeated rows and follow the red duplicate references.
6. Confirm shared Google Sheets and Wiplash.ai account access request their
   optional host permissions only after the related user action.

Core editing, local imports, printing, and PDF export require no account.
