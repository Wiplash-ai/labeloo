# Labeloo Privacy Notice

Last updated: August 4, 2026

Labeloo processes address text and label projects locally in your browser. It
does not transmit addresses, selected webpage text, browsing history, project
data, or settings to Wiplash or any other third-party backend service.

The extension uses browser storage to retain your current project and the
context-menu selection waiting to be added. It uses the context-menu permission
only to offer “Add address to Labeloo” for text you select. It requests no host,
history, identity, analytics, or network permissions.

Removing the extension deletes its extension-managed local data according to
your browser's normal extension-removal behavior. The standalone web app uses
that site's local browser storage, which you can remove through browser site-data
controls.

Future optional synchronization would require a separate disclosure and an
explicit opt-in. The local-only V1 does not provide synchronization.
