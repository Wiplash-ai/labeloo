Privacy should stick.

Labeloo is local-first. You can build and print label sheets without creating an account or sending address data to us.

Local workflow

The browser app and extension save label projects in browser storage on your device. Printing is performed by your browser. Labeloo does not upload a local project merely because you edit, import, export, or print it.

Local data remains until you clear it, uninstall the extension, reset browser storage, or remove it yourself.

Optional accounts and sync

If you choose cloud sync, we process your name, email address, password hash, project names, label and address content, project revision history, and basic security metadata needed to operate the account. Synced content is transmitted only after you sign in and connect the project.

Signing out does not delete the local copy. Deleting a cloud project or account removes the associated synced data, subject to limited security backups and legal retention duties.

Commercial API

API users may submit address data for import normalization or PDF rendering. Those request bodies and generated PDFs are processed to return the requested output and are not saved as cloud projects unless the caller separately uses a project-sync endpoint.

We retain hashed API credentials, usage counts, operation types, timestamps, and security logs for authentication, billing, abuse prevention, and reliability. API keys are shown once; only hashes are stored afterward.

What we do not do

  • We do not sell address lists or synced project content.
  • We do not use label content for behavioral advertising.
  • We do not require cloud sync to use the editor or printer.
  • We do not intentionally collect payment-card details in Labeloo.

Extensions and third parties

If another browser extension appears on a Labeloo page or print dialog, that extension is controlled by its own permissions and policies. Labeloo does not activate unrelated extensions. Optional sync is hosted by Wiplash.ai; links to browser stores or external services are governed by those providers.

Security, children, and changes

We use access controls, scoped API keys, password hashing, encrypted transport in production, and revision conflict checks. No system is perfectly secure. Labeloo is not directed to children under 13.

We may revise this policy as the service changes. Material changes will receive a new effective date.

Your choices

You can use Labeloo locally, sign out while retaining a local copy, delete individual cloud projects, revoke API keys, or delete your account. For privacy requests, email support@wiplash.ai.
